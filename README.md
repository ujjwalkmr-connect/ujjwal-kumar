# Ujjwal Kumar 3D Portfolio

A production-ready Vite + React + TypeScript 3D portfolio using React Three Fiber, Drei, GSAP, Lenis, Framer Motion, React Spring, Tailwind, and GitHub Pages deployment.

## Local setup

```bash
npm install
npm run dev
```

## Add your real photo

Place your image at:

```bash
public/ujjwal-photo.jpg
```

The site will use `photo-placeholder.svg` until this file is added.

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

1. Push to a GitHub repository.
2. Go to Settings → Pages.
3. Source: GitHub Actions.
4. Push to `main`; the workflow deploys `/dist`.
